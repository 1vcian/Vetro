# Allow-list of the public repository (ADR 0034), read by tools/export/public.sh.
#
# One rule per line: a kind, a space, a path relative to the repository root
# (a file, or a folder and everything under it).
#   +  public: exported
#   ~  transitional: private by target, still exported because a public crate
#      or module needs it to compile (ADR 0034, "Coupling"); --strict drops it
#   -  private: never exported (listed so that a new, unlisted path shows up
#      as "unclassified" in the export report instead of being forgotten)
#   !  deny pattern (extended regex): an exported text file matching it stops
#      the export (infrastructure addresses, keys, private hostnames)
# The longest matching path wins, so a rule on a file overrides the rule on
# its folder. A tracked file matched by no rule is private and reported as
# unclassified (an error with --strict).

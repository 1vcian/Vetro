First start: the home screen is downloaded as a ready-made snapshot of the machine (about 500 MiB, kept in the browser's private storage, OPFS), then it resumes in seconds; from the second start nothing is downloaded again. The disk is read in pieces with HTTP Range as the system needs it.

Machine
Options

The guest is not drawing (scanout off): this demo uses the serial console, the text box of the page. The screen turns on when a program draws (with Android, the phone).

The system is booting: the screen turns on when the graphics start (surfaceflinger); the phases are in the panel next to it.

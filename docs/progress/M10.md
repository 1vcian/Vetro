# M10 — progress log

## 2026-09-26 (core of the machine's record & replay, Analysis agent)
- **Done:** deterministic record & replay of the system machine (ADR
  0018, `docs/specs/replay.md`). A single host entry point,
  `Machine::input(Input)`: console, virtio-input keyboard and pointer, GPIO,
  display, network frames from the host (`Input::NetFrame`, new: queue in
  `NetLink`, snapshot `FORMAT_VERSION` 3), link, vsock, host
  connections towards the guest (`Input::HostNet`: `vetro-cli`'s `--hostfwd` and
  `vetro-wasm`'s `vetro_net_*` converted); the `device`/`net` closures
  during a recording become opaque events that stop the replay.
  Versioned log (`"VETROREC"`, `LOG_VERSION` 1: events with instruction,
  CPU hash and console bytes; keyframes; start and end
  fingerprints). Replay (`start_replay`, `replay_from`) that cuts quanta at
  events (the JIT does not go past them), `goto` jump from the nearest keyframe,
  `read_phys`/`read_virt`/`translate`/`registers_text`; inputs during
  `Stop::Blocked` deferred to the end of the quantum after unblocking. CLI
  `vetro boot --record=FILE [--keyframes=N]`, `--replay=FILE`, `--goto=N
  [--dump=VA:BYTE]`. Green tests: `vetro-machine` (bare-metal probe: quanta
  of 1/7919/2^40, keyframes, goto to 9 points, escaped input and opaque
  access detected, disk waiting), `tests/boot/tests/replay.rs` (guest
  kernel: keys one at a time, DHCP/HTTP/ping, ICMP frame from the host, keyboard,
  20 KB echo from a host connection, `sleep`, power-off; replay
  identical with interpreter and JIT, goto with the same registers and RAM, log without
  a key or without the ICMP frame → divergence at the first event after),
  `crates/vetro-cli/tests/boot_replay.rs`; all `tests/boot` tests with
  the oracle, `vetro-cli` in release, `VETRO_JIT=1 --test vetro`, clippy,
  fmt, `cargo test --workspace`, wasm32 build. Measurements (release, macOS Apple
  silicon, machine shared with other agents, best of two): session
  of 782.9 M instructions with 43 inputs; log of 22 145 bytes without keyframes,
  81.6 MB with 8 keyframes (~10 MB each, one every 100 M instructions); time
  3.07 s without recording, 3.44 s recorded without keyframes (+12 %:
  start and end fingerprints, 1 GiB of RAM to scan each), 4.11 s with
  keyframes (+34 %), replay 2.87 s. The guest kernel is the one rebuilt on
  main (b99c407); ADR 0019 because 0016–0018 are taken.
- **Missing:** recording and replay in the browser (log export, keyframes in
  OPFS, wasm API); incremental keyframes (today full snapshots, ~0.1–1 s
  and ~10 MB each); `Upstream` boundary for the M7 relay when it

## 2026-09-26 — TLS hooks: plaintext HTTPS in the HAR (Analysis agent, ADR 0029)
- **Done:** TLS hooks on top of the invisible breakpoints (ADR 0027).
  `vetro-machine::tls::TlsTracer` puts breakpoints on
  `SSL_write`/`SSL_read`/`SSL_write_ex`/`SSL_read_ex` of `libssl.so`
  resolved from each process's ELF symbols (system BoringSSL and
  Conscrypt's), captures the plaintext (SSL_write on entry, SSL_read
  on return via LR with a breakpoint set the first time it is seen),
  ties the connection to the 4-tuple from the `connect` fd on the same thread
  (`Linux::socket_endpoints` from `struct sock`, offsets from BTF:
  `layout::SockLayout`) and to process/library. `tls_service` installs the
  hooks of new processes between two quanta. Conversations become
  `vetro_analysis::net::TlsConversation` and `NetworkAnalysis::merge_tls`
  reconstructs them as `secure` HTTP requests with attribution, merged with
  the plaintext ones in the inspector (`view`: `secure`, `attribution`) and
  in the HAR (`_secure`, `_vetro`). `vetro boot --tls` (with `--har`/
  `--net-requests` and `--kernel-profile`). Snapshot at boot_completed:
  `vetro boot --save-on=TESTO:FILE [--save-delay=S] [--exit-after-save]`.
  Tests: unit (`net::tls`, `merge_tls` in the HAR, `socket_endpoints` via
  BTF), `vetro boot --tls` on the test kernel (profile loaded, hooks
  active, no crash; without libssl 0 conversations). Test app
  `tests/apps/vetro-probe` (HTTPS POST with JSON, built with the SDK).
- **Missing:** the sinkhole's TLS endpoint so that the app's connection
  completes (the sinkhole terminates TCP): primitives ready and verified with the
  RFC vectors but not integrated; to be done with the TLS 1.3 server, tested against
  `openssl s_client`, **or** the development CA in the image's trust store
  (AOSP rebuild, VM off) or the test app ignoring the
  certificate. Long test on Android from a snapshot (`VETRO_ANDROID=1`): 10
  apps with plaintext HTTPS tied to the action — not done yet (needs the
  snapshot at boot_completed and the TLS endpoint). Causal attribution
  to user input (with the timeline).
- **Blocked:** the M7 exit waits for the Android snapshot and the TLS
  endpoint (or the CA in the image). The build VM is off: the user
  turns it back on for the rebuild with the development CA.

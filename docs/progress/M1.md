# M1 — progress log

## 2026-09-24
- **Done:**
  - ADR 0005 (ARMv8.0 level, oracle `-cpu cortex-a53`), ADR 0006
    (random programs in Rust instead of RISU for M1), spec `docs/specs/cpu.md`.
  - `vetro-cpu`: complete decoder for the v8.0 integer instructions (data
    immediate and register, branches, exceptions, system at EL0, load/store in all
    forms, pairs, literals, exclusives, acquire/release, CRC32), with a
    distinction between `Undefined`/`Unimplemented`; reference interpreter;
    `UserMemory` with permissions.
  - `vetro-cli`: static ELF loader (pages as in Linux), user mode process
    with write/exit, `vetro run` command.
  - `vetro-diff`: harness with a dump of x0–x30, SP, NZCV and memory; random
    generator; `tools/a64asm.sh` for test encodings.
  - `tests/isa`: 72 per-instruction cases, green on Vetro and identical to QEMU.
  - Exit criterion: 2000 random programs (seeds 1000–2999) identical to
    QEMU, 209 of them with an expected trailing SIGILL; 250 by default in CI.
  - Mutation test: a deliberate error in the 32-bit V flag is detected
    (3 programs out of 100).
- **Problems found along the way:** QEMU in Docker hung on
  SIGILL because it ran as PID 1 (fixed with `--init`) and wrote core
  dumps (disabled). `llvm-objdump` prints `.word`s in memory order and
  the assembler emits relocations for `adrp x, .+N`: the script now handles
  the first case and rejects the second.
- **Missing:** nothing for the criterion: GitHub CI green (run 36026368592). Sensitivity to 32-bit flag bugs is
  low per program: the nightly run uses 20000 cases.
- **Blocked:** nothing.
- **Next (M2):** real syscalls, signals, TLS/`TPIDR_EL0` at boot,
  SIMD/FP (needed by musl and BusyBox), real RISU as apprentice.
